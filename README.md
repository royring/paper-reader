# 论文阅读器 · Paper Reader

## 启动方式(必读)

数据**全部保存在本地文件夹**(不依赖浏览器存储),并附带一个 Python 本地服务器解决浏览器 CORS 限制:

```powershell
cd paper-reader
双击 start.bat            # 或命令行: python server.py(纯标准库,无需 pip)
# 服务器在控制台窗口前台运行,方便看日志;自动打开浏览器 http://localhost:8517
# 停止:窗口内 Ctrl+C 或直接关窗(stop.bat 也可停止)
```

- 所有数据都在 `paper-reader/data/` 文件夹,**每篇论文一个独立子文件夹,互不干扰**,拷贝该文件夹即可整体迁移:
  - `data/config.json` — 多平台 AI 配置
  - `data/papers/<论文id>/meta.json` — 该论文的记录(目录/标注/笔记/对话会话/总结/关联)
  - `data/papers/<论文id>/original.pdf` — 该论文原文
  - `data/papers/<论文id>/translation.json` — 该论文整篇翻译进度
  - 删除论文即删除整个子文件夹;单篇备份/迁移只需拷贝对应子文件夹
- AI 对话、语音转写、arXiv 下载均由 Python 服务器转发(`server.py`),不受浏览器跨域限制;arXiv 转发仅放行 arxiv.org 域名。
- 首次启动时,若检测到旧版浏览器 localStorage 中的 AI 配置,会自动迁移一次;旧版单文件 records.json 也会自动拆分为各论文独立文件夹(原文件留作 .bak)。


## 功能

### 1. AI 阅读(多平台多模型接入)
- **多平台**:⚙ AI 设置中可添加多个 OpenAI 兼容平台(内网 vLLM/Ollama/LiteLLM 或 OpenAI/DeepSeek 等),每平台可配多个模型(逗号分隔),支持逐平台测试;**顶栏下拉随时切换全局模型**(影响翻译/总结/讲解),**对话框下方可单独为对话选模型**。
- **多模态对话**:对话框支持 📎 上传**图片**(vision 直传)、**视频**(自动抽取最多 4 帧)、**语音**(自动调用 /audio/transcriptions 转成文字);🎤 按钮可直接录音,结束后自动转写。
- **arXiv 搜索**:顶栏「🔎 arXiv」按关键词检索 arXiv,结果可一键**下载 PDF 并添加到阅读器**(自动归入 arXiv 目录)。浏览器跨域受限时自动走公共 CORS 代理。
- **AI 总结**:自动读取全文(最多前 20 页)生成结构化中文摘要,独立标签页,自动保存。
- **AI 对话**:右栏向 AI 提问,自动携带当前页上下文。
- **选中翻译 / AI 讲解**:在 PDF 中选中一段话 → 浮动工具条 → 🌐 翻译 或 🤖 AI 讲解。
- **整篇翻译(独立标签页「📄 整篇翻译」)**:纯网页重排版 —— 每页为白色网页(不渲染 PDF 画面),文字按段落块(自动识别双栏)翻译后按原位置重新排版,图片直接从 PDF 提取并按原位置嵌入,公式以 KaTeX 渲染;翻译按段落进行、不要求行数对应,AI 漏译的段落自动单独补译。标注支持 **Ctrl+Z** 回退;高亮只标记你选中的那一次,不会重复标记页内其他相同文字。右栏宽度可拖拽调整(边缘细条),记忆宽度。
- **翻译当前页**:右栏「🌐 选中/单页」标签内,只翻译当前页为连续文本。
- **翻译语言默认中文**,右栏下拉可切换(English、日本語等,可在设置中自定义)。

### 2. 数学公式处理
- 所有 AI 提示词强制要求:公式改写为规范 LaTeX(`$...$` 行内、`$$...$$` 独立),变量符号一律保留不译,译文用 KaTeX 渲染,保证公式正确显示。

### 3. 标注功能
- 选中文字后点浮动条色块(黄/绿/蓝/粉)即高亮;点 📝 添加笔记。
- 标注列表在右栏「🖊 标注」,可点击定位到原文页,可删除。随论文持久保存。

### 4. 历史记录与关联
- 打开过的 PDF 自动存入左侧文献库(PDF 与记录均保存到 `data/` 本地文件夹),关闭后进度、标注都在。
- 文献库按**目录路径**组织成树(「移动到目录…」输入 `深度学习/Transformer` 这类分层路径)。
- 「添加论文关联…」手动建立论文间的引用/相关关系(双向)。**关联仅在相同文件夹内建立,跨文件夹不提供**;**🔗 关系图** 按文件夹查看(顶部下拉切换),展示该文件夹内论文及关联连线,点节点可直接打开。

## 数据位置
- 全部数据在本机文件夹:`paper-reader/data/`(config.json / records.json / papers/<id>/…)。拷贝整个 `data/` 即可备份或迁移到别的电脑。界面偏好(面板宽度)仍存在浏览器本地,不影响数据迁移。
